Steam 早期评论与后续口碑
Python scikit-learn 时间切分验证

问题：对首月好评的游戏，能不能用前 30 天的评论，提前排出后续更可能跌出好评档的作品？

方法：以数据集里的首条评论时间为起点，前 30 天构造特征、第 30–365 天观察变化；L2 正则化逻辑回归，按首条评论年份做时间切分测试。

结果：测试集 AUC 0.886、AP 0.343；风险排序前 10% 的游戏里 30.2% 后来跌出好评档，约为基准率的 5 倍；滚动 7 折 AUC 中位 0.861。

看板可查样本外游戏的风险排序、前后期好评率与实际结果；数据截至 2023-11。

手游榜单结构分析工具
Python pandas 集中度与分层指标

问题：报告要对每个品类给出「值不值得进」的判断，但榜单导出只有排名和规模，看不出结构。

方法：五年榜单走同一套 Python 流程，算集中度、分层增长贡献、新品渗透和跨年轨迹；口径规则写进代码——总量与份额只在排序轴上算，跨年在榜只用固定 Top N。

产出：30 余项指标的 Excel 底表与字段说明，供四份年度报告直接取数。

原始数据不随仓库发布。

Game Radar
Python SQLite Apple RSS

问题：Apple 只提供当前榜快照，没有历史接口；想知道某个榜日进了哪些新游戏、后来还在不在榜，只能自己按天存。

方法：每 12 小时抓一次中美日韩 Top 100，用 Apple 公开接口取榜单与产品信息，名次和产品资料按榜日存进 SQLite。

产出：三页静态页——当日榜、前一榜日、周报；展示首次进榜、名次变化、上架时长与品类构成，玩法简介、玩法类型和中文译名由 LLM 辅助生成。

16 个榜日快照；129 项数字断言可逐条回查。
