整体盘子
五年间美国手游下载量从 51 亿降至 37 亿次（CAGR -8%），收入从 173 亿升至 185 亿美元（CAGR +2%），2025 年收入几乎零增长（+0.3%），已是存量市场；其中量价表现都好的赛道很少，4X、二合是仅有的两个。
品类趋势
  • 下载增长靠前的品类中，方块解谜、纸牌接龙 RPD 低、收入高度集中（纸牌接龙收入 Top10 占 95%），进入回报有限；4X 量价表现都好，Kingshot 说明「塔防吸量＋SLG 变现」的新品路径仍走得通。
  • 收入增速最高的二合（+82%）、即时策略（+81%）、卡牌对战（+59%），增长压在一两款头部产品上——Gossip Harbor 一款占二合收入 57%，Clash Royale 单款增量超过即时策略全品类增量；是头部在放量，不是赛道在扩容。
  • 五年持续增长的品类极少：下载侧仅方块解谜、纸牌接龙、4X，收入侧仅二合。
横向判断
  • 素材端：核心玩法展示持续让位给数字门、数字祖玛这类休闲副玩法素材，「素材玩法 ≠ 游戏玩法」成了获量常态。
  • 用户端：会话次数普降、单次时长稳定在 7–10 分钟，使用越来越碎片。
  • 商业化端：礼包占比在多个品类反超直充。
结论
  • 4X、二合、对消可关注，需靠题材或剧情差异化切入。
  • 卡牌对战、即时策略 + 顶级 IP 可以跑出较好收入，不适合正面进。
  • 平台 / 跑酷、沙盒等连续收缩的赛道不建议进入。

2021–2025 美国手游题材趋势研究
年度报告 · 美国板块
研究问题：五年里美国各游戏题材的盘子怎么变，题材和玩法怎么组合还有进入机会
核心发现
  • 头部题材座次基本不变，增量集中在烹饪、丧尸等少数题材，多由「轻题材吸量＋重度玩法变现」的组合打法驱动。
  • 已验证组合：烹饪 + 合成（烹饪收入增量超七成来自合成）、丧尸 + 休闲副玩法 + 4X（超休素材吸量 + 4X 变现）。
  • 时尚、犯罪、军事领跌（头部老产品衰退、新品承接不足）。
进入判断：可关注 烹饪 + 合成 / 模拟经营、丧尸 + 休闲副玩法 + 4X；时尚 + 二合 / 换装、装饰 + 收纳整理需靠题材和剧情差异化切入（女性向）；军事、农场、载具汽车等玩法同质、RPD 偏低的题材不建议进入。

我的角色
负责美国题材板块的数据整理、分析与成稿
数据与工具
基于 Sensor Tower 双平台数据（Game IQ 主题标签、月度原始表），Excel 透视表按题材汇总下载 / 收入 / RPD（中英对照表 VLOOKUP）；头部产品数据取自 ST 应用排行榜；题材内产品按五年均 RPD 划分轻度 / 中重度
整体格局
美国手游题材大盘以轻度休闲为主、头部格局稳定；题材主要承担吸量功能，多个题材验证了「轻题材吸量＋重度玩法变现」的路径。
题材趋势
  • 烹饪是唯一收入、下载双增的头部题材（下载 +6%、收入 +50%），由 Cookingdom、Good Coffee, Great Coffee 等新品带动；帝国建造下载 +15%、RPD 24.4 美元，量价齐升；丧尸题材下载持平但收入 +39%，由 Last War: Survival、Last Z 两款 SLG 驱动。
  • 时尚、犯罪、军事领跌，共性是头部老产品衰退、新品承接不足；载具汽车下载 -11% 但收入 +40%（Car Match 单款增收 963 万美元），属存量深耕而非盘子扩容。
  • 合成玩法持续向题材渗透：烹饪收入 Top5 中 4 款是合成（Tasty Travels、Merge Cooking、Flambé 贡献超七成收入增量），装饰题材的头部增量也来自「合成 + 剧情」（Matching Story、Seaside Escape）。
横向判断
  • 获量端：ASMR 成为轻度题材新品的共性手段——Cookingdom、Jelly Master、Satiszone 等都靠「ASMR 音效 + 即时反馈 + 无压力进度」支撑下载，题材内新老产品代际更替明显。
  • 供给端：成熟题材内的换皮矩阵仍有效（Supercent 商店经营系列），「低成本验证—换皮迭代」的题材打法成立。
结论
  • 可关注：烹饪 + 合成 / 模拟经营、丧尸 + 休闲副玩法 + 4X。
  • 需差异化切入：时尚 + 二合 / 换装、装饰 + 收纳整理（女性向）。
  • 不建议进入：军事、农场、载具汽车等玩法同质、RPD 偏低的题材（载具汽车收入 +40% 系单款驱动、非盘子扩容）。

2021–2025 中国 MMO 头部产品趋势研究
年度报告 · 中国板块 · 热门方向

核心发现

规模概况
五年持续萎缩——下载从 1.30 亿降至 3,794 万（CAGR -26%），收入从 21.1 亿降至 8.8 亿美元（CAGR -20%）。但 RPD 从 16.3 美元升至 23.2 美元：盘子在收缩，留下来的用户付费深度在提高，是明确的存量深耕市场。五年中唯一明显的缓冲是 2023 年《逆水寒》通过买休闲用户扩量，成为上线首年下载最高的 MMO。
头部格局
  • 固化且获量极难：2025 年收入 Top10 中 6 款是上线近十年的老产品；仅两款新品进入 Top10：《龙之谷世界》走龙之谷 IP 怀旧 + 端游还原，《仙遇》主打「遇见端游时代的自己」，靠轻日常、轻社交做减负。
  • 新品的共同生存策略是经典 IP + 降低负担。
买量素材
即时制与回合制同向变化：高福利卖点上升（即时制 4%→23%、回合制 15%→29%）、高品质美术卖点下降（回合制 63%→44%）——玩家更吃「低门槛、高回报」的数值爽点；新品靠 IP / 情怀卖点补位。
内购结构
  • 即时制：直充 50% + 礼包 37% 为主，占比上升主要由《仙遇》《龙之谷世界》《新剑侠情缘》三款新进榜产品带动，老产品内购结构基本没动。
  • 回合制：直充占比高达 83%（梦幻西游 RPD 131.9、幻唐志 RPD 227.9，付费深度极端），但占比上升主因是两款产品出榜——是榜单结构变化，不是在榜产品的行为变化。
结论
  • MMO 盘子收缩、头部固化、获量成本高，不建议正面进入。
  • 可行路径已被两款新品验证：经典 IP 情怀打底 + 高福利素材买量 + 轻负担设计。

细分赛道
按「规模—集中度—头部粘性—进入路径」拆四条：
  • MMORPG：四国下载 2025 年齐创五年新低，付费能力分化极端——韩日 RPD 55 美元以上，中国约 23 美元。头部固化：中国收入 CR10 为 60%、韩国 71%，且除《逆水寒》《冒险岛：枫之传说》外，新品几乎无法在收入 Top10 维持满两年；可行路径是怀旧 IP + 数值轻度化。
  • 放置 RPG：四条赛道中近年唯一还有过增长的（美日韩 2024 年见顶、2025 年小幅回落）。韩国下载量最大，日本 RPD 最高；收入集中度也最高——中国 CR10 达 84%。爆款生命周期极短（韩国《菇勇者传说》收入一年跌 90%），怀旧 IP 是跨市场验证过的确定性打法（冒险岛 Idle 在美日韩同时进榜）。
  • 卡牌 RPG：日本 RPD 42.6 美元、四国最高，中国不足 15 美元、最低。老牌 IP 粘性接近事实垄断：美国《RAID》连续五年收入榜首，日本《FGO》22–25 年连续榜首；韩国 2025 年靠重制 IP《七骑士 Re:BIRTH》拉动回升。美日韩进入难度都大，建议止步于差异化题材观察。
  • 开放世界：高门槛、高风险，无顶级研发配置不建议进入——《原神》之后五年仅 7 个项目熬到上线、其中 2 款速死，没熬过研发期的项目是这个数量的数十倍；存活路径只有两条：《鸣潮》式挖掘未被满足的需求，或《燕云十六声》《无限暖暖》式切入差异化人群，共同前提是顶尖美术与玩作品质，且获量靠营销与社媒自传播而非买量。
结论
  • 可关注——放置 RPG（差异化吸量题材 + 怀旧 IP 矩阵）、中韩 MMORPG（怀旧 IP + 轻度化）。
  • 谨慎——卡牌 RPG（头部 IP 粘性垄断，建议止步于差异化题材观察）。
  • 不建议——开放世界（研发资源门槛决定这不是选题问题，是禀赋问题）。

报告要判断「这个品类值不值得进」，依据是市场结构而不是总量规模。这套脚本把这些结构指标按品类 × 年份算齐，输出分页签底表，作为各品类章节的取证来源。

背景

  • 报告需对每个品类形成「是否值得进入」的判断，依据是市场结构而非总量规模：头部垄断程度、增长由哪一层产品贡献、新品的渗透与变现水平、头部产品所处的生命周期阶段、赛道内产品的同质化程度。
  • 上述结构指标须按品类 × 年份逐一计算且全程口径一致，故编写 Python 脚本统一处理，输出按分析维度分页签的指标底表，作为各品类章节的取证来源。
我的角色独立设计指标口径并编写全部代码，品类、题材两个维度复用同一套流程。

做了什么

  • 数据清洗：兼容 Sensor Tower 导出的多种格式（tab 分隔，utf-16 / utf-8 / gbk 三编码自动回退），5 年数据分块读取、内存降级（float32 / int32），20 多个原始英文字段统一成标准口径。
  • 结构指标计算（30 余项，按四类问题组织）
    • 集中度：CR3/5/10 及高 / 中 / 低垄断分层；头部 / 中腰部 / 尾部（40% / 70% 阈值）增长贡献；Top10 产品下载与收入双维度贡献。
    • 效率：分层吸量效率，及增长（增长值 ÷ 上线天数）、留存（DAU ÷ 下载）、变现（RPD）三个效率维度。
    • 生命周期：新品渗透率、增长贡献、RPD 溢价；存量按成熟（1–3 年）/ 衰退（3 年以上）分层，计算产品年龄与下载增长的 Pearson 相关。
    • 机器学习聚类：以产品名为输入做无监督聚类，流程为文本预处理（去停用词、词干提取）→ TF-IDF 向量化 → K-Means，用轮廓系数在 2–8 中自动选择聚类数，输出各簇关键词。产出两个层面：各聚类的产品数、下载与收入占比、RPD 及增长贡献对比；以及两个校验——头部收入前三是否集中在同一聚类、新品进入头部聚类的比例，用于观察头部产品是否趋同。
  • 输出：6 张底表 Excel（集中度 / 吸量效率 / 新品 / 存量 / 聚类汇总 / Top10 详情）+ CR5、吸量效率五年对比图。
应用报告成稿前的品类结构量化分析，覆盖透视无法计算的指标；换数据文件夹即可复用于其他国家 / 年份。　产出可运行脚本 + 全字段指标字典。
